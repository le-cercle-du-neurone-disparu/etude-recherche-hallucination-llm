# etude-recherche-hallucination-llm

Veille sur la détection d'hallucinations des LLM : groupes de travail, papiers de
recherche et publications grand public.

**Dossier en ligne : https://le-cercle-du-neurone-disparu.github.io/etude-recherche-hallucination-llm/**

Support documentaire des projets [berlue](https://github.com/le-cercle-du-neurone-disparu/berlue)
(backend de détection) et [aletheia](https://github.com/le-cercle-du-neurone-disparu/aletheia)
(interface).

## Fiabilité des sources

Le dossier distingue explicitement ce qui est établi de ce qui reste à confirmer — voir sa
dernière section. En particulier : les identifiants arXiv 2026 n'ont pas été ouverts un par un,
et les taux d'hallucination relayés par les pages agrégatrices sont sans méthodologie traçable.
Vérifier avant toute citation.

Recherche initiale : septembre 2026. Le sujet se périme vite ; les shared tasks et les
leaderboards vivants sont les points d'ancrage qui tiennent le plus longtemps.
